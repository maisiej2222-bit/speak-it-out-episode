🚀 Netlify 部署

Speak It Out Episode 1 - 完全免费，无需信用卡

✅ Netlify 优势：无限带宽、免费 HTTPS、Serverless 函数支持、每月 100GB 流量

方式一：拖拽上传（最快，30 秒上线）

1
打开 Netlify Drop
2
把 /Users/chenhong/speak-it-out-project 文件夹整个拖到上传区域
3
等待部署完成（约 30 秒），获得类似链接：
https://your-site-123456.netlify.app

方式二：GitHub 同步（推荐，自动部署）

1
登录 Netlify
2
点击 Add new site → Import an existing project
3
用 GitHub 登录，选择 speak-it-out-episode1 仓库
4
点击 Deploy site

✅ 部署完成后：

课程页面：

https://your-site.netlify.app/

挑战页面：

https://your-site.netlify.app/challenge.html

排行榜：

https://your-site.netlify.app/leaderboard.html
📱 学生使用：
发送挑战链接给学生，他们打开后点击 🚀 Start Challenge， 输入名字完成 15 句话，成绩自动提交到排行榜。
