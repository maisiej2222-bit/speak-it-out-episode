🚀 Railway 部署指南

Speak It Out Episode 1 - 3 分钟上线

✅ 优势：自动 HTTPS、免费额度、支持后端 API、数据库集成

📦 步骤 1：准备代码

代码已准备好，包含：

  • server.js - Express 服务器
  • package.json - Node.js 依赖
  • index.html - 主挑战页面
  • leaderboard.html - 排行榜页面

🔗 步骤 2：连接 GitHub

1
打开 Railway Dashboard
2
点击 New Project → Deploy from GitHub repo
3
授权 Railway 访问 GitHub，选择你的仓库
YOUR_USERNAME/speak-it-out-episode1

🚀 步骤 3：部署

1
Railway 会自动检测 Node.js 并安装依赖
2
等待部署完成（约 1-2 分钟）
3
点击 Settings → Domains → Generate Domain

✅ 完成！

你的网站地址：

https://your-app-production.up.railway.app

点击 domain 旁的 🔗 图标即可访问

📱 学生使用：
把 Railway 链接发给学生，他们打开后滚动到 Module 01: Word Bank， 点击 🚀 Start Challenge 即可开始挑战。

🏆 排行榜：访问 https://your-app.railway.app/leaderboard.html
💡 需要先推送代码到 GitHub：
在终端运行（替换 YOUR_USERNAME 为你的 GitHub 用户名）： cd /Users/chenhong/speak-it-out-project git remote add origin https://github.com/YOUR_USERNAME/speak-it-out-episode1.git git push -u origin main
