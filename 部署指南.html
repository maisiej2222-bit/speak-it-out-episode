🚀 Speak It Out Episode 1

部署指南 - 3 分钟上线

✅ 推荐方案：GitHub Pages
完全免费，无需密码，通过图形界面操作

📦 步骤 1：创建 GitHub 仓库

1
打开 GitHub 创建页面
2
Repository name 输入：speak-it-out-episode1
3
选择 Public → 点击 Create repository

📤 步骤 2：上传代码

在仓库页面点击 uploading an existing file

1
把 /Users/chenhong/speak-it-out-project 文件夹里的所有文件拖到上传区域
2
输入 Commit message：Initial commit
3
点击 Commit changes

🌐 步骤 3：开启 Pages

1
进入仓库 Settings → 左侧 Pages
2
Source 选择 Deploy from a branch
3
Branch 选择 main / /(root) → Save

✅ 完成！

等待 1-2 分钟部署完成后，你的网站地址：

https://YOUR_USERNAME.github.io/speak-it-out-episode1

（替换 YOUR_USERNAME 为你的 GitHub 用户名）

📱 学生使用：
把链接发给学生，他们打开后滚动到 Module 01: Word Bank， 点击 🚀 Start Challenge 即可开始挑战。
