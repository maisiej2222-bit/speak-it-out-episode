🚀 Railway 部署指南

Speak It Out Episode 1 - 双页面版本

✅ 两个页面说明：
1. 课程页面 - 完整词汇学习 + 互动挑战（适合课堂）
2. 挑战页面 - 独立挑战（学生可随时访问）

📁 项目文件

📚 index.html 课程主页面（词汇 + 挑战）
🎮 challenge.html 独立挑战页面
🏆 leaderboard.html 排行榜页面
⚙️ server.js Express 服务器
📦 package.json Node.js 配置

📦 步骤 1：推送到 GitHub

1
在终端运行以下命令： cd /Users/chenhong/speak-it-out-project git remote add origin https://github.com/YOUR_USERNAME/speak-it-out-episode1.git git push -u origin main ⚠️ 替换 YOUR_USERNAME 为你的 GitHub 用户名

🚀 步骤 2：Railway 部署

1
打开 Railway Dashboard
2
点击 New Project → Deploy from GitHub repo
3
授权 Railway 访问 GitHub，选择 speak-it-out-episode1 仓库
4
Railway 会自动检测 Node.js 并部署（约 1-2 分钟）

🌐 步骤 3：生成域名

1
部署完成后，点击 Settings → Domains
2
点击 Generate Domain
3
获得你的专属链接

✅ 部署完成后的链接：

课程页面（主页）：

https://your-app-production.up.railway.app/

独立挑战：

https://your-app-production.up.railway.app/challenge.html

排行榜：

https://your-app-production.up.railway.app/leaderboard.html
📱 学生使用流程：
1. 发送挑战页面链接给学生
2. 学生点击 🚀 Start Challenge
3. 输入名字，完成 15 句话挑战
4. 查看成绩并提交到排行榜
