🚀 Speak It Out Episode 1 - 部署指南

项目位置：/Users/chenhong/speak-it-out-project/

✅ 本地测试：直接双击打开 index.html 即可在浏览器中运行。排行榜数据保存在本地浏览器中。

方式一：Vercel 部署（推荐，5 分钟上线）

1 上传到 GitHub

在终端运行以下命令：

cd /Users/chenhong/speak-it-out-project
git remote add origin https://github.com/你的用户名/speak-it-out-episode1.git
git push -u origin main

2 访问 Vercel

vercel.com/new

用 GitHub 账号登录 → 导入项目 → 点击 Deploy

3 获取链接

部署完成后获得链接：

挑战页面：https://你的项目.vercel.app
排行榜：https://你的项目.vercel.app/leaderboard.html

方式二：Netlify Deploy（拖拽上传）

1 访问 Netlify

app.netlify.com/drop

2 拖拽文件夹

将 speak-it-out-project 整个文件夹拖到上传区域

3 获得链接

部署完成后获得类似链接：https://xxx-xxx.netlify.app

方式三：GitHub Pages（免费）

1 推送到 GitHub（同方式一步骤 1）

2 开启 Pages

进入仓库 → Settings → Pages → Source 选择 main → Save

3 获得链接

https://你的用户名.github.io/speak-it-out-episode1

📱 学生使用流程

课堂使用：
  1. 打开挑战页面
  2. 滚动到 Module 01: Word Bank
  3. 点击 🚀 Start Challenge
  4. 输入名字，完成 15 句话
  5. 查看成绩和排行榜

🏆 多人排行榜说明

⚠️ 重要：本地版本说明
当前版本使用浏览器 LocalStorage 存储数据。
  • 同一设备：所有学生轮流使用同一设备，成绩自动保存
  • 多设备：需要部署到云端并使用云端 API，或手动导出/导入 JSON 合并数据

导出/导入方法：

  1. 学生完成挑战后点击 📤 Export My Score
  2. 将生成的 JSON 文件发送给老师
  3. 老师在排行榜页面点击 📥 Import Scores 合并所有成绩
